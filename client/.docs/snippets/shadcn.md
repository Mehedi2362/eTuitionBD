# shadcn/ui Code Snippets

Fast code snippets for all shadcn/ui components with both **alias** (short) and **full** naming conventions.

## Quick Reference

| Prefix Pattern | Type           | Example     |
| -------------- | -------------- | ----------- |
| `i;comp`       | Import (alias) | `i;button`  |
| `i;fcomp`      | Import (full)  | `i;fbutton` |
| `;comp`        | Usage (alias)  | `;button`   |
| `;fcomp`       | Usage (full)   | `;fbutton`  |
| `;compb`       | Basic usage    | `;buttonb`  |

## Features

- ✅ **Placeholders**: Use `Tab` to jump between placeholders (`${1:placeholder}`)
- ✅ **Choices**: Select from dropdown options (`${1|option1,option2|}`)
- ✅ **Final cursor**: `$0` marks where cursor ends after snippet

## Tips

1. Type the prefix and press `Tab` or `Enter` to expand
2. Use `Tab` to navigate between placeholders
3. Use arrow keys to select from dropdown choices
4. Press `Esc` to cancel snippet expansion
